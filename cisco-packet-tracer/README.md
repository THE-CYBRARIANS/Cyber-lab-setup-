# 🖧 Cisco Packet Tracer Installation Guide

Cisco Packet Tracer is a network simulation tool used to practice networking and Cisco configuration without physical hardware.

## 📥 Download

Download Cisco Packet Tracer from Cisco Networking Academy:

[Download Cisco Packet Tracer](https://www.netacad.com/resources/lab-downloads)

> You may need to sign in or enroll in Cisco's free "Getting Started with Cisco Packet Tracer" course to access the download. [oai_citation:0‡Cisco Networking Academy](https://www.netacad.com/courses/getting-started-cisco-packet-tracer/1000?utm_source=chatgpt.com)

## 💻 Installation

### Windows

1. Download the Packet Tracer installer.
2. Open the downloaded installer.
3. Follow the installation wizard.
4. Accept the license agreement.
5. Choose the installation location.
6. Click **Install**.
7. Launch Cisco Packet Tracer after installation.
8. Sign in with your Cisco/NetAcad account if required.

### Linux

1. Download the Linux version.
2. Open the terminal.
3. Navigate to the directory containing the downloaded file.
4. Follow Cisco's installation instructions.
5. Launch Packet Tracer.

## ✅ Verification

After installation, open Cisco Packet Tracer and create a simple network containing:

- 1 PC
- 1 Switch

Connect the PC to the switch and confirm that Packet Tracer is working correctly.
