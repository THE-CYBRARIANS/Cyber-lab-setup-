💻 Requirements

Before installing any of the resources, make sure your system meets the requirements listed in the individual guides.

Some resources may require:

* A 64-bit computer
* Sufficient RAM and storage
* Virtualization support
* VirtualBox or VMware
* A stable internet connection

⸻

⚠️ Important

Always download software from its official source and check the system requirements before installation.

If you encounter an issue during installation, check the troubleshooting section of the relevant guide or open an issue in this repository.
