# 🐉 Kali Linux Installation Guide

Kali Linux is a Linux distribution designed for cybersecurity, penetration testing, digital forensics, and security research.

## 📋 Requirements

- 64-bit computer
- VirtualBox or VMware
- At least 4 GB RAM recommended
- Sufficient storage space
- Stable internet connection

## 📥 Download

### Kali Linux

[Download Kali Linux](https://www.kali.org/get-kali/)

### VirtualBox

[Download VirtualBox](https://www.virtualbox.org/)

### VMware

[Download VMware](https://www.vmware.com/)

## 🖥️ Installation Using a Virtual Machine

1. Install VirtualBox or VMware.
2. Download the Kali Linux virtual machine image.
3. Extract the downloaded file if necessary.
4. Open VirtualBox/VMware.
5. Import the Kali virtual machine.
6. Start the virtual machine.
7. Complete the initial setup.
8. Log in to Kali Linux.
